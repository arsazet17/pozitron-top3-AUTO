# Жёсткое правило Зеркала

Зеркало +15 — отдельная система наблюдения за строгими тройниками.

**Запрещено:**
- добавлять MIRROR в masterRank;
- начислять ему MASTER points;
- учитывать его в MAIN / Algorithm / APP CORE / SHIFT;
- использовать его попадания для изменения основного selector;
- смешивать mirror KPI с MASTER KPI.

**Разрешено и обязательно:**
- вести базы и life=15;
- фиксировать pre-fact тройники;
- проверять их после факта отдельно;
- хранить mirrorAudit и mirrorHitLog;
- показывать на страницах «Тройники» и «Зеркало».
