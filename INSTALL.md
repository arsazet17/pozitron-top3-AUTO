# TOP-3 CHAT MASTER — полная замена прогнозирования + ЗЕРКАЛО ОТДЕЛЬНО

Этот пакет заменяет ОСНОВНОЕ прогнозирование приложения системой из чата.

## Основной прогноз
- MAIN SIGNAL-POOL: LAST Δ + TIME-DIRECTION.
- PERM→FAMILY Algorithm.
- скрытые APP CORE / MATRIX SHIFT.
- MASTER → ровно 3 итоговые комбинации.
- работа над ошибками, RAW, digit support, algorithm watch, no-backfit.

## Зеркало — НЕ основной прогноз
Зеркало +15 сохранено полностью. Оно:
- продолжает вести активные базы;
- продолжает искать строгие 000/111/…/999 тройники;
- имеет отдельные страницы «Тройники» и «Зеркало»;
- имеет отдельный mirrorAudit / mirrorHitLog;
- НЕ входит в MASTER;
- НЕ получает score;
- НЕ влияет на три основные комбинации;
- НЕ участвует в классификации ошибок основного прогноза.

## Установка
Скопировать содержимое ZIP поверх корня репозитория с заменой файлов.
Файлы `js/engine/mirror15.js` и `js/pages/mirror.js` ОБЯЗАТЕЛЬНО сохранить.
