# TOP-3 AUTO

Автоматическое планшетное PWA-приложение для проекта TOP-3.

## Что внутри
- 7 экранов: Главная, Прогнозы, Архив, Алгоритм, Зеркало, Статистика, Настройки.
- Адаптивный портрет/альбомный режим планшета.
- Одна кнопка **Обновить**: проверяет версию приложения и свежесть данных.
- GitHub Actions каждые 5 минут проверяет официальный источник `https://www.stoloto.ru/top3`.
- Историческая база TOP-3 встроена в `data/archive.json`.
- Основные контуры: TOP, Δ, ЧИСЛА, Доп №1/№2, Сканер, Запаздывающий.
- Отдельный модуль `TOP3-ЗЕРКАЛО-15-СТРОГО-21.08.2026`.
- Отдельный экран матрицы смены алгоритма.

## Важный строгий режим
`data/rules.json` содержит законы проекта. Модуль **смены алгоритма** подключён, но по умолчанию не создаёт цифры, потому что точная числовая формула выбора A/B/C из матрицы не была формализована. Это сделано специально: приложение не имеет права выдумывать дополнительный прогноз.

## GitHub Pages
1. Создать репозиторий `pozitron-top3-AUTO`.
2. Загрузить содержимое этого ZIP в корень репозитория.
3. Settings → Pages → Deploy from a branch → `main` / root.
4. Actions должны иметь `Read and write permissions`, чтобы автосборщик мог сохранять новые тиражи.

## Обновление версии
Изменить `data/version.json`. Кнопка **Обновить** увидит новую версию и перезагрузит приложение.

## Источник
Официальная страница TOP-3 Столото. Автосборщик не использует ручной ввод.
