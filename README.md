# TOP-3 AUTO

Автоматическое планшетное PWA-приложение для проекта TOP-3.

## Что внутри
- 8 экранов: Главная, Прогнозы, Слежение, Тройники, Зеркало, Архив, Статистика, Настройки.
- Адаптивный портрет/альбомный режим планшета.
- Одна кнопка **Обновить**: проверяет версию приложения и свежесть данных.
- GitHub Actions проверяет официальный источник Столото и сохраняет новые тиражи.
- Основная датированная база TOP-3 хранится в `data/archive.json`.
- Полный последовательный архив автоматически собирается в `data/full-archive/all.json` из репозиторного XLSX и проверенного хвоста: 267 936 комбинаций, тиражи №11…№267946 на момент сборки 12.09.2026. Для старой части без исходных дат приложение не дорисовывает даты и время.
- Актуальная сетка будущих тиражей: каждые 30 минут, `:25` и `:55` — 48 тиражей в сутки.
- Основные контуры: MAIN, PERM→FAMILY, APP CORE, MATRIX SHIFT.
- Отдельный модуль `TOP3-ЗЕРКАЛО-15-СТРОГО-21.08.2026`.
- Раздел **Тройники** использует полный архив как историческую базу, показывает статистику 000…999 и лидера новых рождений сигналов за последние 20 проверок без двойного счёта продления.

## Важный строгий режим
`data/rules.json` содержит законы проекта. Зеркало остаётся отдельным от MASTER: оно не получает MASTER score и не меняет три основные комбинации.

## Полный архив
`scripts/build_full_archive.py` читает исходный XLSX напрямую, проверяет направление архива по известным тиражам, объединяет его с `data/bootstrap-tail.json` и только после контрольных совпадений создаёт браузерный файл полного архива. При несовпадении проверочных тиражей сборка останавливается — архив не подгоняется и не перезаписывается молча.

## Обновление версии
Изменить `data/version.json`. Кнопка **Обновить** увидит новую версию и перезагрузит приложение. Service Worker использует отдельное имя кеша для каждой сборки.
